- Type: milestone

The sketch review identified an input problem, not a solver problem. Design
Studio made the pydantic design contract visual and gave photographed sketches
a reproducible path into source YAML without adding a hosted dependency.

## What we did

- Added `python -m openair.designer` to produce one self-contained,
  network-free `design-studio.html`.
- Embedded `VehicleSpec.model_json_schema()`, field paths, bounds, units, and
  the selected design so the form derives from the same contract as Python.
- Added live top, side, and front SVGs based on the repository's trapezoid and
  station equations, with handles for wing, fins, bays, tank, and stations.
- Added quick estimates for area, aspect ratio, MAC, panel/body mass,
  full/reserve static margin, fin volume, and packing.
- Added browser-side YAML import/export, preserved quoted values such as NACA
  `"0012"`, omitted computed fields, and regenerated the sketch envelope from
  edited geometry. Headless export round-tripped through `VehicleSpec`.
- Added image underlays, opacity and calibrated grid controls, four-point
  projective rectification using a dependency-free 8x8 solve, direct tracing,
  and rectified-image download.
- Added `new <concept> --open` and `edit <concept>` workspaces. The local
  token-protected server validates a complete `design.yaml`, `brief.md`, and
  sketch bundle, stages it, then atomically creates the concept on first save.
- Updated the creation workflow so new concepts start with design authoring and
  a baseline geometry checkpoint rather than silently copying a template.
- Reduced the README to a first-design quickstart and added `ARCHITECTURE.md`
  as the canonical system and lifecycle map.

## Outcome

The Studio provided an offline, schema-complete authoring path from measured
sketches to canonical YAML. Invalid YAML or filenames left no partial concept,
and a successful save returned the next pipeline command. The workspace
implementation closed with 80 tests passing and two stretch tests deselected.

## Lessons and follow-ups

Generated previews are disposable views; `design.yaml` remains the source of
truth. Atomic save, schema round-trip, and measurement provenance matter as
much as interactive graphics. The browser representation still needed a
restricted OpenVSP round-trip and stronger schema-native interaction, which
became the next increments.
